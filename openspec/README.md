# OpenSpec

This directory is the durable product and engineering specification for the intelligent assistant project.

Future agents should read these files before changing code:

1. `openspec/project.md`
2. `openspec/specs/product-capabilities/spec.md`
3. The spec file for the area being changed
4. `AGENTS.md` at the repository root

The specs use normative keywords:

- MUST: required behavior or constraint
- SHOULD: preferred behavior unless there is a strong local reason
- MAY: optional behavior

Secrets, API keys, local machine paths, and one-off test data MUST NOT be written into specs.
